Key Features
Book Data Management: Stores details for each book, including Book ID, Name, Author, Publisher, and Quantity.

Batch Entry: Allows the user to input data for multiple books (set to 3 by default) at the start of the program.

Inventory Display: Provides a formatted list of all books currently available in the system.

Issuance System:

Searches for a book using its unique Book ID.

Verifies if the requested quantity is available in stock before processing.

Automatically updates the remaining inventory after a successful issue.

Technical Overview
Language: C++.

Concepts Used: Classes and Objects, Constructors, Encapsulation (Private/Public members), and Arrays of Objects.

Logic: The program uses a library class to encapsulate book attributes and methods like issue_book() and display() to manipulate that data.
